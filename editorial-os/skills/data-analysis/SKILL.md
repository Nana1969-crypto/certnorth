# Skill: Data Analysis

## Cardinal rule
Every figure is labelled either **SOURCE DATA** or **CERTNORTH CALCULATION**. Never
let a derived number look published.

## Procedure
1. List inputs with source and date.
2. State the method in one line before computing.
3. Compute.
4. Label the output.
5. State assumptions.
6. State what the result does not prove.

## Standard calculations
- Total cost of obtaining a credential (exam + membership + education + retake risk)
- Recurring cost per renewal cycle
- Five- and ten-year cost of ownership
- Annualised cost
- Percentage difference between two figures, and which is the denominator
- Converting percentages into counts (e.g. exam domain weight → question count)
- Ratios between sources reporting the same quantity

## Precision discipline
Do not report more precision than the inputs support. If a source says
"approximately $425", the total is approximate. Write "~$755", not "$755.00".

## Comparison discipline
Before comparing two figures, ask whether they measure the same thing the same way.

Recurring traps on this site:
- **Official median vs self-reported average** — these differ by construction;
  self-reported skews high, official medians skew low. Part of any gap is
  measurement, not reality. Say so.
- **A title covering different jobs** — "program manager" and "technical program
  manager" are different roles; averaging across them is meaningless.
- **Different regions or currencies** — do not convert and compare as if equivalent.

## Assumption examples to state explicitly
"Assumes continuous membership." "Assumes 2,080 working hours per year." "Assumes
renewal at every cycle for ten years." "Excludes training costs, which vary widely."

## Never
Round in the direction that strengthens an argument. Present a calculation as a
source's finding. Compare incomparable bases silently.
