# Skill: Fact-Checking

## Scope
Every factual claim: numbers, requirements, dates, rules, attributions, and any
statement a reader might act on.

## Classify each claim
- **VERIFIED** — primary source supports it as written
- **PARTIALLY VERIFIED** — supported in substance, over-specified in wording
- **OUTDATED** — was true, since superseded
- **UNSUPPORTED** — no source supports it
- **MISLEADING** — accurate but creates a false impression
- **INCORRECT** — contradicted by the source

## Blocking
UNSUPPORTED, MISLEADING, INCORRECT and OUTDATED must be corrected or removed before
publication. PARTIALLY VERIFIED must be softened to match the evidence.

## When sources disagree
Do four things, in this order:
1. Name the disagreement and quantify it
2. Explain the likely methodological reason
3. State which figure the article uses and why
4. State the limitation this creates

Never silently choose. Never average incompatible measures.

## Site-wide consistency
The same fact must not appear differently on two CertNorth pages. Check the corpus
before approving. A contradiction between our own pages is worse than a vague
statement.

## The false-precision check
Ask of every exact number: is the source this exact? If the source says
"approximately", so must we.

## Output
`templates/fact-check-report.md`.

## Never
Resolve an unverifiable figure by choosing a plausible one. Accept a number because
it appears on several sites.
